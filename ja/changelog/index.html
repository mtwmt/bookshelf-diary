  1. v1.6.32026-11-24最新バージョン

    電子書籍のマルチプラットフォーム登録

    • 同じ電子書籍を異なるプラットフォームごとに1冊ずつ登録できるようになりました。
    • iOS 17 で起動直後にクラッシュする不具合を修正しました。
    • ボタン・メニュー・フォームのスタイルを統一し、操作感を一貫させました。
    • 既存機能の修正と改善を行いました。
  2. v1.6.22026-11-20

    日本語・韓国語 UI と電子書籍の追加対応

    • 日本語・韓国語のインターフェースを追加しました。
    • 手動で追加・一括追加で「紙の本」または「電子書籍」を選択できるようになりました。
    • 購入記録とシェア画像を「紙の本」と「電子書籍」の2つに分けて表示します。
    • シリーズページからシリーズ全体の作品をシェアできるようになりました（Pro）。
    • 一括追加でスキャンしながら検索し、誤ってスキャンした本を直接削除できるようになりました（Pro）。
    • 並び順の調整時、ワンタップで一番上や一番下へ移動でき、ドラッグ操作もより滑らかになりました。
    • 既存機能の修正と改善を行いました。
  3. v1.6.02026-11-14

    記録・貸出・借入・電子書籍コレクション

    • 「記録」を追加（Pro）：蔵書にない本も評価やメモを残せます。
    • 「貸出・借入」を追加（Pro）：貸した本・借りた本を記録し、返却後も履歴を保持します。
    • 電子書籍コレクションに対応：購入プラットフォームを記録し、紙の本と電子書籍を分けて集計します。
    • 下部「追加」メニューを調整。Pro は購入予定リストから蔵書に追加したり、購入記録をシェアできます。
    • 撮影した表紙を自動でアルバムに1枚保存できるようになりました。
  4. v1.5.02026-10-24

    ブックカレンダー・BookBuddy インポートと改善

    • BookBuddy からエクスポートしたファイルを直接インポートできるようになりました。
    • 既存機能の修正と改善：言語のシステム追従、出品用写真のバックアップ、スキャン・検索・出品の安定性を向上しました。
