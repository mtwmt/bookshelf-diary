How to Use

  1. 1.Export your library from BookBuddy (Export → Excel / CSV)
  2. 2.Upload the exported .xlsx or .csv file here; the converted Excel file downloads automatically
  3. 3.Open Bookshelf Diary → Settings → Collection List → Import, and choose the downloaded file

The converter is free to use; sign-in is required when importing into the app. Free users get 2 total Excel import/export trials; Plus and Pro are unlimited.

With the latest version of the app, you can also go to Settings → Collection List → Other formats and choose BookBuddy to import BookBuddy's .xlsx or .csv directly without converting first. Books that need confirmation will use suggested values and be listed in the import summary. If you prefer to check "Pending Review" books one by one on your computer first, use this converter and follow Step 3 above.
